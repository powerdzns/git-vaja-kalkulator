# Preprost kalkulator

Testni projekt za učenje Gita in GitHuba.

## Funkcionalnosti

- Seštevanje
- Odštevanje
- Množenje
- Deljenje
- Preverjanje deljenja z nič

## Zahteve

Python 3.

## Zagon programa

```bash
python kalkulator.py
```

## Zagon testov

```bash
python -m unittest -v
```

## Namen projekta

Na projektu preizkušam nadzor različic, delo z vejami, združevanje sprememb in uporabo GitHuba.
## Razvoj

Spremembe razvijam na ločenih vejah.

Projekt
Projekt uporabljam tudi za napredne ukaze Git.


## Različica

Trenutna različica je 1.0.0.

Uporabljam obliko MAJOR.MINOR.PATCH:
- MAJOR pomeni nezdružljive spremembe.
- MINOR pomeni nove združljive funkcionalnosti.
- PATCH pomeni združljive popravke napak.
