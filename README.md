# Preprost kalkulator

Testni projekt za učenje Gita in GitHuba.

## Funkcionalnosti

- Seštevanje
- Odštevanje
- Množenje
- Deljenje
- Preverjanje deljenja z nič

## Zahteve

Python 3.

## Zagon programa

```bash
python kalkulator.py
```

## Zagon testov

```bash
python -m unittest -v
```

## Namen projekta

Na projektu preizkušam nadzor različic, delo z vejami, združevanje sprememb in uporabo GitHuba.
